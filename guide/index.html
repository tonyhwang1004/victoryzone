영상 1

단어시험 · 오답노트 사용법

단어시험 보는 날, 시작 전에 한 번 보세요.

  1. 이름 + 학부모님 전화번호 뒤 4자리로 본인확인
  2. 오늘의 시험에서 「지금 응시」 → 「시험 시작」
  3. 영어 단어를 보고 한글 뜻을 적고 Enter (여러 뜻 중 하나만 맞아도 정답)
  4. 틀린 단어는 「📖 내 오답노트」에서 「오답 재시험」
단어시험 보러 가기 →
영상 2

YOU승리 앱 · 플래너 첫 사용

등록하고 처음 앱을 열 때 보세요.

  1. 독서실에서 받은 가입 코드로 회원가입
  2. 홈에서 오늘 입실 시간 · 공부 시간 · 공지사항 확인
  3. 늦거나 빠질 땐 「사유 제출」, 선생님 연락은 「메세지」
  4. 플래너: 공부 시작할 때 「▶ 시작」 → 끝나면 체크 → 「오늘 마무리 · 검사 받기」
