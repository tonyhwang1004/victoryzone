영상 1

대기신청 처리

홈페이지로 새 대기신청 알림(문자 · 메일)이 왔을 때

  1. 알림 메일에서 학생 정보와 학부모 연락처 확인
  2. 학부모님께 연락해 상담 일정 잡기
  3. 메일 맨 아래 링크로 「승리자리 이매점 대기신청」 시트 열기
  4. 처리상태 바꾸기 (예: 신규 → 연락완료 → 상담예약 → 등록) · 메모에 통화 내용 적기
영상 2

신규 학생 등록

새 학생이 등록해서 단어시험 명단에 올려야 할 때

  1. 단어시험 페이지 맨 아래 「🆕 직원: 신규 학생 등록」
  2. 직원 비밀번호로 인증
  3. 이름 · 학부모 전화번호 · 자리번호 입력 → 「✅ 신규 학생 등록」
  4. 화면에 나온 이름 · 학부모 뒷자리 4개를 학생에게 알려 주고, 학생 안내 영상 링크도 함께 보내기
단어시험 페이지 열기 →
영상 3

단어시험 운영

매일 시험 시간: 시험지 출력 → 채점 → 성적 입력

  1. 「🖨️ 직원: 오늘 시험지 일괄 출력」 → 결석생 체크 해제 → 시험지 생성 → 인쇄
  2. 시험을 보고 함께 출력된 정답표로 채점
  3. 「📝 직원: 오늘 시험결과 입력」 → 학생마다 틀린 번호만 입력 (만점은 스페이스 한 번)
  4. 「💾 일괄 저장」 → 학생 오답노트와 성적 기록에 자동 반영
시험지 출력 (단어시험 페이지) → 성적 일괄 입력 →
